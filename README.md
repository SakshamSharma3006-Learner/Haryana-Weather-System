# Haryana-Weather-System
🌦️ Haryana Weather Intelligence Dashboard — A responsive weather analytics platform covering all 22 Haryana districts with live data. Includes real-time conditions, hourly &amp; 7-day forecasts, AQI, alerts, charts, district comparison, search, geolocation, favorites, report export, auto-refresh, and 8 dynamic themes using HTML, CSS &amp; JavaScript.
